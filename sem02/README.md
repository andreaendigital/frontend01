# Pixel Arcade - Semana 2

Segunda versión del proyecto de Desarrollo Frontend I, enfocada en CSS3, layouts y formulario de contacto.

## Avance incorporado

- Hoja de estilos externa en `css/styles.css`.
- Variables CSS para colores, tipografías y superficies.
- Catálogo organizado con CSS Grid.
- Navegación y formulario estructurados con Flexbox.
- Formulario de contacto con nombre, correo, categoría y mensaje.
- Etiquetas visuales para estados de productos.
- Controles de formulario asociados a sus respectivos labels.

- [css/styles.css](css/styles.css)
