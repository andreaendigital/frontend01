# Pixel Arcade - Semana 1

Primera versión del proyecto de Desarrollo Frontend I, enfocada en los fundamentos de HTML5.

## Avance incorporado

- Documento HTML5 con `doctype`, idioma español, charset UTF-8 y viewport.
- Estructura inicial con encabezado, navegación, sección de productos y footer.
- Catálogo inicial de tres productos.
- Imágenes públicas con textos alternativos.
- Enlaces internos y enlaces externos a redes sociales.
